# Matematyczna Przygoda — wersja 2

Gra dla dzieci w wieku 7–8 lat. React + Vite.

## Funkcje
- 3 krainy (do 10, 20 i 100), każda po 50 przykładów: 25 dodawania i 25 odejmowania.
- Dokładnie 3 odpowiedzi do wyboru, jedna poprawna.
- 5 monet za poprawną odpowiedź; bonus 10 monet co 10 działań.
- Sklep: koszulki, czapki, okulary, plecaki i piłki; wybór wyposażenia.
- Bohater widoczny na każdej podstronie; prosty podgląd dodatków na portrecie.
- Zapis postępów w localStorage (na tym samym urządzeniu i w tej samej przeglądarce).

## Uruchomienie lokalne
1. Zainstaluj Node.js.
2. W katalogu projektu: `npm install`
3. Uruchom: `npm run dev`
4. Wejdź na adres wyświetlony przez Vite.

## Vercel
Zaimportuj repozytorium GitHub do Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Uwaga
Obecny portret to wycinek zatwierdzonej ilustracji bohatera. Nakładki akcesoriów są poglądowe, a nie pełnymi animowanymi strojami. Gra nie wymaga konta ani płatności.
